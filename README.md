# Calculator (JavaScript)

A basic JavaScript calculator built with HTML, CSS, and JavaScript that supports the four fundamental arithmetic operations.

## Overview
This project was created to practice JavaScript fundamentals such as DOM manipulation, event handling, and basic expression evaluation.

## Features
- Addition, subtraction, multiplication, and division
- Numeric keypad input
- Clear (C) button to reset the display
- Real-time expression display and evaluation

## Technologies
- JavaScript
- HTML
- CSS

## Usage
1. Open the `index.html` file in your browser.
2. Click the number and operator buttons to build an expression.
3. Press **=** to calculate the result.
4. Press **C** to clear the display.
